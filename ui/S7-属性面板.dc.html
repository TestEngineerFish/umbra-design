面板是真的能点的：标签可以横向拖着调数字，`?` 展开改法说明，「执行」是两段式。
十条形制，左边那块是它们长出来的样子
第 9、10 项不在这份稿里（一个在 S3 顶栏，一个在 S5 的 token 详情），只写结论。第 4 项的通道你们已经建完了，这里只定那两件形态上的事。
01 属性面板整体形制
现在：一行一项，标签 104px + 控件 + 下面一行灰色改法说明。
定成：分三组（样式 / 属性 / 文案），组头可折叠并带条数；行高 30px、标签 96px；改法说明不常驻，行末一个 ? 点开就地展开。
每行都挂一行灰字，十项就是十行噪音。说明是查的时候要，不是看的时候要。
02 数字控件
现在：文本框 + −/+，步长固定 1。
定成：不加滑块。−/+ 保留，连着拖的手感挂在标签上 —— 按住标签左右拖就是调值。步长按单位分：px 走 1（按住 Shift 走 10）、% 走 5、无单位的（line-height 这类）走 0.1。
拖着调是数字控件的主要手感，但不值得再为它占一条滑块的宽度 —— 标签那 96px 本来就闲着。
03 颜色控件
现在：17px 色块 + 文本框。
定成：18px 色块 + 文本框；点色块展开一层，里面是 S5 的 token 检索结果，一行一个色板。不给自由取色器。
这是设计系统工具，颜色的正确答案基本都在 token 里。取色器会让人绕过 token，那正是要拦的那件事。
04 样式字面量的实时预览 通道已建完 · 只剩形态
现在：边敲边改 iframe、不落盘；Enter / 失焦落盘；Escape 取消。底栏一行橙字「预览中，未落盘：style.font-size → 64px」。
定成 · 那条提示：不放底栏。橙色挪到改动的那一行 —— 输入框边框转橙、行末一枚「未落盘」；底栏那条只留键位说明「Enter 落盘 · Esc 取消」。
定成 · 失焦：保留失焦落盘，不加「应用」钮。但落盘那一刻底栏换成绿字「已落盘 v7 → v8」，带一颗「撤销」停三秒。
哪个值没落盘是行级信息，底栏离它太远 —— 和第 6 项同一条理。至于「应用」钮：它让每一次改都多一次点击，而误改已经被 Escape、撤销、版本回退兜了三层。
05 sc-for 里的节点提示
现在：顶上一条橙色胶囊「在 sc-for 里 · 影响每一行」。
定成：改前保留胶囊，不弹窗。改完之后胶囊换成「已改 · 影响 12 行」，长出一颗「撤销」。
事前确认每次都要点，事后撤销只在改错时点。一次误操作的代价小于一百次确认。
06 落盘中的反馈
现在：面板底下一行「正在落盘：…」。
定成：面板底沿一条 2px 进度条 + 一行文字。失败时那一行控件边框转红、行下面出现真实原因和一颗「重试」，值回滚到落盘前。
失败要回到出错的那一行去说。人得知道是哪个值没落下去，不是「有个值没落下去」。
07 不可改项的呈现
现在：只显示值 + 一行改法说明，没有控件。
定成：整行降到 muted，值用等宽字，行末一枚虚线标签说明它是什么（函数 / 引用 / 子组件）；说明仍收在 ? 里。
「不能改」要在扫一眼时就看出来。靠读那行说明太晚了。
08 版本回退的形制
现在：底栏 3 个版本胶囊 + 一颗「执行」。
定成：胶囊保留（最新三版），第四版起收进「更多」。不弹二次确认 —— 改成同一颗按钮的两段式：点一下变「确认回退到 v216」，再点才执行，点别处就撤销。不做时间轴。
回退是危险动作，但弹窗会被肌肉记忆点掉。让危险留在原地比另开一个窗更拦得住人。
09 S3 顶栏的版本位 不在这份稿里
定成：显示最新快照的版本号；工作区与快照不一致时后面挂一枚「工作区」徽标；从来没有快照才写「—」。
版本位要回答的是「我现在看的是不是磁盘上那一版」。快照号加一枚不一致徽标就够了。
10 S5 里 resolved 为 null 不在这份稿里
定成：不跟链。保留「链没解开」，但把断在哪一跳写出来 —— 列出中间那个 token 名，做成可点的，人自己跳过去。
跟链是另一个功能。在不跟链的前提下，告诉人下一跳叫什么，他自己就能走完。
