## 二、M1 · 项目与稿件生命周期

**这一期的目标**：从一个空目录开始，全程只用界面，走完「建项目 → 建稿 →
改名 → 移动 → 复制 → 删除 → 恢复」，期间 `dc-import` 引用一次都不断。

| # | 事情 | 说明 | 验收 |
| --- | --- | --- | --- |
| ⬜ M1-0 | **引用图谱**：`list_references(file)` | 回答「谁 import 了我」「我 import 了谁」。全部生命周期操作的前置（`11` §3.3） | 语料里 `Umbra PC 端`（115 个 import）能正确列出双向引用；孤立稿返回空 |
| ⬜ M1-1 | `create_project` | 建目录 + `project.json` + `.gitignore` + 可选设计系统骨架 + 第一份稿 | 空目录起步建成，立刻 `get_project` 能读、`npm run ui` 能开 |
| ⬜ M1-2 | 工作区与最近项目 | 项目可在任意路径；`projects/` 降级为默认新建位置（依赖 Q5） | 在三个不同路径各建一个项目，最近列表按时间排；删掉目录后列表里标「找不到」而不是崩 |
| ⬜ M1-3 | `create_draft` | 四种来源：空白骨架 / 模板 / 复制现有稿 / 把组件包一层 | 四种各建一份，全部 `validate_draft` 零 error、`render_check` 活着 |
