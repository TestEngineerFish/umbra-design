## 一、第 1 题：从属面板放哪

**统一放右侧一列，底栏只留一行状态。** 和你的倾向一致。

这一列由两部分组成：

- **40px 图标轨**贴在最外侧，常驻。每个面板一个图标，带计数角标：诊断角标用 warn 色，其余用 accent。
- **300px 面板体**在图标轨内侧，同一时刻只开一个。再点一次当前图标，或者点标题栏的 `›`，面板体就收起，只剩图标轨。

理由：R4 好做（会话栏与预览的分界线只跟会话栏宽度有关）；R1 好做（图片 / 目录 / 其他文件整列不出现）；诊断和属性同一列，视线不走 L 形；会话在右时顺序是预览、从属面板、会话；窄窗（< 1100px，R5）图标轨不动，面板体变 320px 抽屉盖在预览上，点遮罩或 Esc 关闭。

**对 S2 嵌入模式的连带影响（需要你们确认）**：`?embed=1` 时 S2 最好只留画布，属性面板由 S11 这一列来装；选中节点和改值走现有的 `postMessage` 通道。这一轮没改 S2。

**R3 建议加一个键**：`layout.panelByKind: { dc: "props" | null, md: "outline" | null }`，`null` 表示收起。
