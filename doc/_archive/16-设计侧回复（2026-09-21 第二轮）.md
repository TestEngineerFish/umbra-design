### 顺带修掉的四个真缺陷

这些不是形制问题，是碰到了就得修：

1. **`--tool-muted-soft` / `--tool-muted-border` / `--tool-bg-2` 三个 token 不存在**
   （`tokens.css` 里没有）。S6 用了 6 处、S10 用了 1 处 —— `var()` 解不开会静默回落，
   所以画面上是「没底色」而不是报错。已换成 `--tool-panel-2` / `--tool-border` / `--tool-canvas`。
   建议给校验器加一条：`var(--tool-*)` 必须在 `tokens.css` 里有声明。
2. **S6 的变更高亮一直没渲染过。** `changes.filter((c) => c.line)` ——
   数据里的字段叫 `at`（`"L45"`），没有 `line`，所以 `leftHighlights` / `rightHighlights`
   恒为空数组。画面视图最核心的东西一次都没出现过，而控制台是干净的。
3. **S6 的滚动同步接不上。** 用的是 `this.refs.rightRef`（legacy string refs），
   而 ref 是类字段 `this.rightRef`，`this.refs` 是 `undefined`。已改成 `.current` 并加了防回弹。
4. **S6 的 `noChanges` 和 `showVisual` 会同时为真** —— 零变更时两栏空画面下面再挂一个空态。
   已互斥。另外演示态 7「清单视图」原来只切 `demo` 不切 `view`，点了没反应，一并修了。

`S6` 的 `spansLabel` 原来在非演示态 5 时是空串，顶栏第二行会塌掉，已给了默认文案。

## 二、一条贯穿全部十屏的口径

**齐边横条 = 这一屏的读数是暂时的 / 不可信的；卡片 = 关于内容的一条提醒。**

- 齐边（无圆角、无边距、紧贴顶栏下沿）：S1「索引已过期」、S2「未落盘」

要把项目名敲一遍 —— 仍然在行内，不弹窗。

## 三、§三 在新底稿上重做

### 3.1 索引已过期

齐边横条紧贴顶栏：时钟图标 + 一行结论（`索引是 08:52 扫的，之后有 3 份稿被改过`）
+ 一行后果 + 改过的文件名（等宽药丸、可换行）+ 右侧一颗实心「重建索引」。
这条横条只有一个出路，所以只给一颗主按钮。

**横幅本身拦不住「数字看起来是新的」**，所以另有行级标记：过期的稿排最上面，
行内挂橙色「文件已改」，元素数 / 版本 / 更新时间三列灰掉（`--tool-muted`）。
健康标签不灰 —— 它是四色契约，灰掉会和「未体检」混。

新增 `staleFileList()` 一个方法统一出数：真数据读 `index_status` 的 `changed + added`，
演示态读 `DEMO_STALE`。横条的数字、文件名药丸、行级标记、底栏那句全部读这一个源。

⚠️ **顺便改了你们演示态 14 的一处假数据**：原来写死
`任务.dc.html · 日志.dc.html · 提醒.dc.html 等 3 份`，但 `NAMES` 里没有「任务」和「提醒」——
横条列出的文件在下面的列表里找不到。已换成池子里真有的三份。这正是 §一 第 2 条那个坑。

**新增键**：`hasStale` `staleHeadline` `staleDetail` `staleFiles[{file}]` `onRebuild`；
行上 `stale` `staleTitle` `metaFg`。
`onRebuild` 现在只清 `s.stale`，接线时换成 `build_index` 调用，回来再拉一次 `index_status`。
旧的 `indexStale` / `indexStaleReason` / `indexStaleFiles` 三个键已删。

### 3.2 版本回退

**底栏三颗胶囊 + 「执行」撤掉了。** 理由：胶囊只能显示版本号，而「要不要退回去」
这个判断需要知道那一版是什么 —— 只看 `v214` 没法决定。

改成顶栏版本号可点 → 352px 弹层时间轴，每行：版本号 · 来源标签（人手改 / AI / 新建）·
时间 · 一句摘要。来源标签给 AI 改的那几版上 accent 底 —— 回退时最想区分的就是
「这是我改的还是模型改的」。当前版高亮在最上、标「当前」、没有回退钮。

- **二次确认在行内**：点「回到这一版」，那一行原地长出橙色确认区，写明
  `现在的 v217 会作为新的一版写下来，历史不删 —— 回退本身也能再回退`。
  不开模态框：回退是可逆的，用模态框拦一个可逆操作是夸大后果。
- **超过 3 版**：列表自滚（最高 420px，约 6 行），不分页。版本历史是「往回翻一点」，
  不是「浏览全部」，分页控件在这里是多余的。

你们原来那条注释说「胶囊留在底栏不进面板，因为进面板要先选中节点」——
那个判断是对的，而且新形制更强：顶栏版本号跟稿名、元素数同居，本来就不需要选中任何东西。
`doRevert()` 一个字没动，`onUndoSave` / `onUndoList` 照旧调它。

**接口缺口（要你们补）**：`s.chg.versions` 只是一串版本号，没有时间 / 来源 / 摘要。
弹层里这三项读 `s.chg.versionMeta[版本号]`，缺了就不渲染（`hasSrc` / `hasSummary` 两个开关）。
所以现在 LIVE 下弹层能开、能回退，但每行只有版本号。
`versionMeta` 补上之后不用改稿。建议形状：

    versionMeta: { "v216": { src: "AI" | "人手改" | "新建", time: "今天 08:31", summary: "…" } }

`src` 就三个取值。`summary` 一句话，用 S4 那份变更数据里最重的一条就够。

**新增键**：`verOpen` `toggleVer` `closeVer` `versions[]` `verCountLabel` `verOlderLabel`
`verBtnBg/Bd/Fg`。`versions[]` 每项：`label` `src` `hasSrc` `time` `summary` `hasSummary`
`isCurrent` `canRevert` `confirming` `confirmLabel` `confirmText` `ask` `cancel` `go`
外加 `fw/bg/dot/ring/srcBg/srcBd/srcFg`。
**已删**：`canRevert` `versionOpts` `hasMore` `moreLabel` `moreTitle` `onExec`
`revertLabel` `execBg` `execBd` `execFg`。
`s.revertArmed` 从布尔改成「存版本号或 false」，`onDocClick` 那套 `armGuard` 豁免照用。

### 3.3 ① 未落盘提示

顶栏下方齐边横条：橙点 + 「预览中 · 未落盘」+ 等宽药丸写**具体那一条改动**
+ 「文件还是 v217」+ 「落盘 `Enter`」「放弃 `Esc`」。

药丸里必须是真实的节点地址和属性名 —— LIVE 下取
`[data-ud-node="…"] · ` + `s.previewing`。不写「有未保存的改动」：
人改完一个数值去拿咖啡，回来要能从这一条看出改的是哪个节点的哪个属性。

和属性面板里的行级橙边 + `r.pending` 标不重复：
**行内回答「哪一行没存」，横条回答「整屏有没有未存的东西」**—— 面板滚走了也看得到。

`onCommit` 现在 LIVE 下是空的，要你们接到 `applyProp`（和字段上回车同一条路）。
两颗钮是多一个入口，不是必经之路。

### 3.3 ② 失焦落盘 —— 保持现状，不加应用钮

三重保险已经够：行内未落盘标记让改动可见、落盘后 3 秒可撤销、版本回退兜底（且可再回退）。
加一颗应用钮的代价是**每次调数值多一次点击**，而那是这个面板最高频的动作；
误改的代价只是多一个版本号。

## 四、§二 四屏形制

### 2.1 S6 版本对比

**并排比例与分隔：50 / 50 固定，分隔线不可拖。**
同一份文档的两栏必须保持可比 —— 拖动分隔线会让一侧换行方式变掉，
制造出「看起来像差异但其实是布局」的假差异。这是对比视图里最贵的一种误导。

**滚动同步：双向对等，不分主从。** 主从要求人知道哪一边是主，而那是个看不见的状态。
给一颗显式的「滚动已同步 / 已解锁」钮：需要对照两端不同位置时才解锁。
实现上加了防回弹（设对面 `scrollTop` 会再触发一次 `onScroll`）。

**四级高亮的配色与强度 —— 不给同等强度**：

| 级 | 处理 |
| --- | --- |
| L1 契约 | err 填色 + 实线描边，要抢眼 |
| L2 取值 | warn 填色 + 实线描边 |
| L3 文案 | 只描边，不填色 |
| L4 等价 | 灰虚线，整颗压到 0.75 |

L4 按定义就不是真变更。把它涂成和 L1 一样重，眼睛就会一视同仁 —— 四种填色是圣诞树。

**四颗级别标都能点（筛选）。** 80+ 条时这是唯一能把画面变小的开关，
筛选同时作用于画面视图和清单视图，总数那句会变成「显示 26 / 84 项」。

**版本选择器：两行 12 颗胶囊换成两颗下拉夹**（`v216 ▾ → v217 ▾`）。
胶囊列开的代价是顶栏一半宽度，而版本区间是看一眼定下来、之后很少再动的东西。
形制和 S2 顶栏的版本号一致，两屏同一个手势。

**两个极端态**：

- **无差异**：两栏整个收掉，只给一句 `v214 和 v215 没有差异` + 为什么 + 一颗「回变更清单」。
  保留并排但两边一个高亮都没有，会让人去找一个不存在的差异 —— 收掉分栏本身就是结论。
- **80+**：筛选 + **步进器**（`上一处 / 下一处` + `3 / 84` 计数）+ **当前差异条**。
  80 条时人不会滚着找，会一条一条跳。

**关于画面高亮的一句实话**：画面上画高亮需要真节点坐标，演示内容里没有。
所以我没在假坐标上画条 —— 改成「当前差异条」用文字说清这一条是什么
（级别 + 目标 + 行号 + `旧值 → 新值`）。等真几何接上，把高亮挂到真节点上，
这条横条仍然有用（它回答「我现在停在第几条」）。

**UI-4 那条不变**：S6 独立窗口 / 整页，不进底栏。

### 2.2 S8 项目设置

**左 Tab 这个组织方式是对的** —— 设置是并列的类别，不是一条流程。但它得有容器：
原来 160px 的 Tab 栏和内容区是两个浮在空白里的物体，宽窗下那根栏没有东西扣着。
现在整个收进**一张面板**（max-width 900、居中、Tab 栏是它的左列、中间一条分隔线），
Tab 栏给 `--tool-panel-2` 底色。一个物体，不是两个。

**危险操作怎么和普通设置拉开距离** —— 三层，都不靠加红：

1. Tab 栏里它前面加一条分隔线，标题与图标染 `--tool-err`。它和上面四项不是同一类东西。
2. 按钮**一律描边**，只有确认那一颗是实心的。平时就摆一颗红实心钮是在邀请人点它。
3. 归档用 warn、删除用 err、重命名/移动用中性 —— 后果不同级，颜色就不同级。
   「归档只是搬目录，随时能移回来」这句写在确认区里。

**二次确认统一一种**：行内两段式（同 §二 的口径）。
不可逆的那条多一道：把项目名敲一遍，敲对之前确认钮是禁用态（0.45 透明 + `not-allowed`）。
项目名抽成模块常量 `PROJECT_NAME`，和基本信息那一格同源 —— 不然改了一处另一处就成假数据。

**回收站不独立成屏。** 它是项目范围内、很少去的一个列表；独立成屏意味着
恢复 / 彻底删除两套行要实现两遍。S1 的入口深链到这个 Tab 就够。

四条危险操作现在走 `dangerRows[]`（`title` `body` `btn` `confirmText` `confirmLabel`
`needsType` `arming` `blocked` `ask` `cancel` `go` + 配色键），
`onRenameProject` 那四个空函数已删，接线时接 `go`。

### 2.3 S9 会话面板

**消息流与工具调用怎么分层 —— 工具调用留在内联，但要绑到回合上。**
原来 AI 消息只有一颗 24px 圆头像，工具卡看起来像直接长在页面上。
现在给整个 AI 回合一根左栏（顶部 7px accent 点 + 往下一条 2px `accent-soft` 竖线），
消息和它下面的工具调用全在这根栏右边 —— 工具调用是上面那句话的**证据**，
得看得出它们属于同一个回合。

**工具调用改单行**：`✓ set_prop  file=…, at=L131 ……… ok`。
名字 + 参数 + 结果摘要同一行，参数和结果各自 ellipsis，完整内容在 `title` 里。
连续调六个工具时不会把对话流撑成一屏卡片。运行中那一行换 accent 底 + 转圈。

**流式输出**：不用闪烁的打字机光标 —— 闪烁的东西在会话流里一直在抢注意力。
正在写的那一段底下给一条 2px 的 accent 横线，安静且同样看得见。回合左栏顶部的点换成转圈。

**中断按钮位置：换到「发送」那个位置上，不在顶栏。**
一个控件位、两种状态 —— 跑着就是「中断 `Esc`」，否则是「发送」。
跑着的时候手就在输入框旁边，不该让人往回跑到顶栏去停。

**用量摆哪：底栏，但只留一个数 —— 花费**（通道 B 是调用次数）。
`1,284 tokens` 收进 `title`。花费是人会拿来停手的数字，token 数是诊断用的。

**和 S2 并排时的宽度与可收起**：默认 380px，可拖 320–520。
收起成 36px 竖条，条上留通道字母 + 一颗未读点 —— **收起后条不能消失**：
AI 在收起状态下仍然在跑，那条竖条是你知道它还在跑的唯一凭据。
（这份稿单独打开时我锁在上限 520px 并靠左，按整屏宽度评审这个侧栏会得出错结论。）

### 2.4 S10 组件 Props 面板

**四种控件和 S7 共用一套 —— 必须共用。** 行法照 S7：
左标题 92px + 右控件，一行 30px。说明与类型收进 `?`（点开在行下面展开一行）。
原来每行四层（名 / 类型 / 说明 / 控件 / 默认值）约 100px，20+ 个 props 就没法看了。
每行常驻一个「默认值」四个字但不给值，是纯噪声，删了 —— 默认值进 `?` 里。

具体：`text` 单行输入框 · `number` `− [值] +`（`type="text" inputmode="decimal"`，
就是 §5.2 那条）· `boolean` 30×17 开关 + 开/关 · `enum` ≤3 个短选项做分段，
更多就该收成下拉（这一条留着，演示数据里还没有超过 3 个的）。

**`null` 项怎么弱化 —— 两件事**：整行压到 0.6，值用等宽 + 一颗「只读」签；
并且**统一沉到列表底部**，前面加一条「不可调（回调 / 对象）」小标题。
原来按声明顺序排，`onClick` 夹在可改的行中间，扫视线被打断。

**「没有 props」的空态**：说清缺的是什么、怎么补 —— 面板读的是 `data-props` 里
`editor` 非 null 的项，这份稿的 `data-props` 是空的，下面给一行能照着抄的 `data-props`。
不是一句「这份稿没有 props」。

**20+ 时：先分组，不急上搜索。** `data-props` 已经支持 `section`，
按 `section` 折叠分组是作者的意图，永远有意义；搜索是作者没给 section 时的兜底，
过 12 个再出现。（现在的实现是「可调 / 不可调」两组，`section` 分组等你们的演示数据里有 `section` 再接。）

**顺带修了 S10 的水平溢出**：`text` 输入框 `width: 100%` 但 `box-sizing` 是 content-box，
加上 padding 和边框就超出列宽，面板底下常年挂一条横向滚动条。已加 `box-sizing: border-box`。
另外类型签原来 nowrap 且没有 `min-width: 0`，长 union 类型（`'primary'|'danger'|'ghost'`）
直接把面板顶开 —— 类型收进 `?` 之后这个问题从根上没了。

**演示态切换钮不在 props 面板里** —— 你们本来就摆在顶栏，对的，没动。

### 2.5 S1 生命周期入口摆位

**一条分界**：**项目名下拉管所有「关于这个项目」的事，顶栏右侧管「关于这份列表」的事。**

原来「切换项目 / 新建项目 / 项目设置」在下拉里，而「新建稿件 / 回收站」是顶栏两颗独立按钮 ——
这个划分是任意的。按上面那条分界：

- **回收站挪进项目名下拉**（项目级、很少去，占不到顶栏一个常驻位），后面带一个数量
- **新建稿件留在顶栏右侧**（列表级、最高频，而且 UI-6 已经定了顶栏加这一颗）

顶栏右侧因此只剩一颗实心钮，项目名区域成了唯一的项目级入口。

**行内操作：常驻，但压到 0.45，hover / 聚焦 / 选中行回到 1。**
hover 才出现对键盘和触控都失效，而且列宽会跳；常驻发暗能保住布局稳定。
**只给一颗 `⋯` 触发器**，四个动作不展开到行上 —— 行是给人扫读数据的，不是工具栏。

**删除到回收站：不提示，但要能撤销。** 不弹确认框（可逆操作弹窗是夸大后果），
也不只给一个飘走的 toast。让那一行**原地塌成一行**
`已移到回收站 · 撤销`，5 秒后消失。和 S2 / S7 / S8 同一套行内撤销语法。
（这一条我只给形制，没动你们的 `deleteDraft` —— 它现在是空函数，塌行状态要一个
`s.justDeleted` 之类的键，接线时一起加更省事。）
