## 一、9.1 布局

```
┌ 顶栏 40 ─ [◰] 项目名 ▾ ······································· [目录][调试][聊天] ┐
├ 目录 240 ─┬ 详情（弹性，正文 ≥ 480）──────────────────────────┬ 聊天 380 ─────┤

│           │ 编辑栏 36（默认收起）          │ 属性区 300       │               │

├───────────┴────────────────────────────────┴──────────────────┴───────────────┤
│ 调试 200（默认关）                                                              │
```

### 1. 顶栏三颗

图标画的是框里的那一条边：`region-tree`（左边一条竖线）· `region-bottom`（下边一条横线）· `region-chat`（右边一条竖线）。按下是 accent-soft 底加 accent 色，和编辑栏里的开关是同一种样式。

| 钮 | 快捷键 | 说明 |
| --- | --- | --- |
| 目录 | ⌘B | 键没变，第八轮就是它 |
| 调试 | ⌘J | 你们回执里定的 |
| 聊天 | ⌘\\ | 键没变，管的东西也没变（还是会话），只是换了边。⌘L 聚焦输入框照你们定的，聊天关着就先打开 |

⌘⌥B 空出来了，给属性区。编辑栏给 ⌘E。

顶栏右边原来那个带底色的钮组去掉了底，三颗直接排。顶栏是窗口级的，不算模块，所以它是 40 不是 36，和下面拉开一档。

### 2. 每个模块的状态栏放什么

| 模块 | 状态栏 | 删掉的 |
| --- | --- | --- |
| 目录 | 项目名（点它 = 在详情区打开根目录）· ⌕ 转到文件 · ⋯ | 收起钮（第 14 条） |
| 详情 | **就是 Tab 条**，Tab 之上不另加一条。右端固定三颗：✎ 编辑栏 · ◨ 属性区 · ⋯ 这份文件 | 原来的「文件工具栏」一整行 |
| 聊天 | 引擎 ▾ · 历史 | 底部的 token 和「运行中」（第 4 条，去了调试栏） |
| 属性区 | 分页图标（稿有五页，md / 图片只有一页时只写标题）+ 当前页名 | —— |
| 调试 | 输出 · 工具调用 · 连接 ······ 运行状态 · 本轮用量 · 布局读数 · 清空 | —— |

**目录的 ⋯ 和在空白处右键是同一张菜单**：新建稿件… · 新建目录 ─ 定位当前文件 · 全部折叠 ─ 重建索引（右边写上次时间）· 在访达中显示。重建索引扫的是整个项目，空白处就是项目根，放在这里不会让人以为只重建某个目录。两个入口指向同一个对象、列的是同一张单，不算一件事两个入口。

详情不另加一条的理由：Tab 条本来就是「这一块里开着什么」，是详情的状态；再加一条，正文上方就又多 36 px，跟第 12 条相反。

### 3. 让位顺序 R2–R5

R1 不变：正文永远是最大的一块，下限 480。其他三样按「多久用一次」排，最不常用的先让：

| 步 | 条件 | 让成什么 | 演示态 |
| --- | --- | --- | --- |
| R2 | 属性区开着，正文 < 480 | 属性区改抽屉，浮在正文右边；Esc 或点正文就收，不改 `layout.props` | 28（1280） |
| R3 | 正文 < 480 | 目录让位；顶栏目录钮点开是浮层（280），选中文件或 Esc 就收 | 29（1024） |
| R4 | 还不够 | 聊天从 380 收到 320 | 30（800） |
| R5 | 还不够 | 聊天也让位，顶栏聊天钮点开是从右边出来的浮层（380） | 31（720） |

理由：属性区是看完一眼就关的；目录是挑文件时用、挑完就不看；聊天是一直在说话的，最后让。让位时顶栏钮的「按下」表示**看得见**，所以让位后它是弹起的，点它出浮层。

### 4. 拖宽手柄

聊天在右，手柄在它的**左边沿**（320–520，双击回 380）。目录手柄在右边沿（200–360），调试在上边沿（120–420）。属性区固定 300，不给手柄：它是看一眼的东西，多一个可拖的边就多一个要记的状态。

## 二、9.2 状态栏高度：一律 36

**算模块状态栏的**：目录头、Tab 条、聊天头、属性区头、调试栏头。五条都是 36，底边一条 1 px 分隔线。

**不算的**：顶栏（窗口级，40）、编辑栏（它是 Tab 条下面的一行工具，也做成 36，这样和属性区头的底线连成一条）、S12 / S13 视图内部的行。

一个值的理由不只是整齐：三列并排时，三条状态栏的底线在同一个 y 上，横着看是**一条线贯穿全屏**。现在 44 / 34 / 34 混着用，这条线断成三截，用户说的「高度不一致」看到的就是这个。

状态栏里的钮一律 28 × 28，图标 16。

## 三、9.3 详情的三层

### 1. 编辑图标

`edit`（一支笔），在 **Tab 条右端**，位置固定，不跟着格式变。**展开是往下推正文**，不浮在正文上：浮上去就盖住稿的顶部，而稿的顶部常常就是要改的导航。高度 0 ↔ 36，180 ms；里层贴底，看起来是从 Tab 条下面推出来的。

**✎ 按下 = 编辑态，抬起 = 预览态。** 这一颗顺手吃掉了原来「编辑 / 预览」两档：收着的时候稿里的交互可以点，展开以后点选才开。

编辑栏的开合**记在页签上**（`editBy[path]`），不是全局：一份在改，另一份在看，切页签时各自保持。

### 2. 属性区收起态：完全收掉

不留 40 px 的图标轨。理由就是你们引过的那条的延伸：属性区默认收起，留一条轨等于常驻一列没人看的图标，跟第 12 条相反。开关在 Tab 条右端（`region-props`）。诊断有提醒而属性区收着时，这颗钮右上角挂一个 6 px 的 warn 点，打开属性区就消。

展开 0 ↔ 300，240 ms，从正文右边推出来。属性区属于详情，底栏开着时它和正文一起被截短（演示态 23）。

### 3. 高频开关：留，但不留在编辑栏里

分两类：

- **看稿用的**常驻，浮在**正文右下角**一小块，不占一行：稿的浅深 · 宽度·缩放 · 演示（`.dc.html`）；缩放（图片）。它们回答「稿在屏上长什么样」，看稿时一直会用
- **改稿用的**进编辑栏，默认收起：

| 格式 | 编辑栏 |
| --- | --- |
| `.dc.html` | 点选 · 撤销 · 源码 |
| `.md` | 源码 / 分栏 · 撤销（展开即进源码编辑，收起回到渲染阅读） |
| 图片 | 圈选 |
| 目录 | 范围 · 排布 · 多选 |
| 代码 / 其他 | 没有编辑栏，✎ 不出现 |

「编辑 / 预览 / 源码」三档里，编辑和预览并进了 ✎，源码进编辑栏。所以看稿时切来切去的那一下，现在就是 ✎ 本身，并没有多点一次。

这条推翻第七轮「文件工具栏常驻」，按交办单说的以这一轮为准。

## 四、9.4 浮层：一套形制，全项目一份

先说三个缺陷的原因，修法都在形制里：

- **引擎下拉超出左边界、Markdown ⋯ 弹不出来**：浮层挂在列里，被列的 `overflow: hidden` 裁掉了，定位也只按列算。→ 浮层挂到窗口最上层，按窗口算位置
- **点别处不收起**：点在稿的 iframe 上，事件不冒泡到外层。→ 打开时铺一层透明的接盘层，点哪里都先关浮层（这一下不穿透）

### 1. 定位

- 贴触发元素下沿 4 px，**起始边对齐**
- 右边放不下 → **结束边对齐**（聊天栏最右那颗历史钮就是这样，演示态 21）
- 下面放不下 → 翻到上面（正文右下角的宽度·缩放，演示态 33）
- 上下都放不下 → 放在空间大的那一边，限高，里面滚动
- 离窗口边至少 8 px
- 右键菜单贴着指针出现，间距 0，规则同上（演示态 10、16）

### 2. 宽度

| 类 | 宽 |
| --- | --- |
| 菜单 | 跟内容走，最窄 200、最宽 320，超出省略 |
| 选择器 | 固定：引擎 280 · 历史 320 · 页签列表 300 · 转到文件 320 |
| 信息卡 | 固定：宽度·缩放 232 |

不跟随触发元素的宽度。唯一例外是表单里的下拉（NewDraftSheet 的「位置」），那种和输入框一样宽。

### 3. 动画

出现：120 ms，opacity 0 → 1，同时从触发元素那一侧位移 4 px 进来（在下面就从上往下，翻到上面就从下往上），曲线 `cubic-bezier(.2, 0, 0, 1)`。**不缩放。** 消失：80 ms，只淡出。

### 4. 三类

| 类 | 用在 | 内边距 | 行 | 分隔线 |
| --- | --- | --- | --- | --- |
| 菜单 | 项目菜单、目录 ⋯、所有右键、文件 ⋯ | 4 | 28，一行字 12，右边快捷键 mono 11 | 1 px，左右各缩 6，上下 4 |
| 选择器 | 引擎、历史、页签列表、转到文件 | 4 | 36，两行（12 + 11），左边 16 px 勾选位 | 用分组小标题（11 muted），不用线 |
| 信息卡 | 宽度·缩放 | 10 / 8 | 里面是控件，不按行 | 同菜单 |

共同：圆角 `--tool-radius-lg`，1 px `--tool-border-strong`，`--tool-shadow-2`。可选一行头（11 px muted），比如右键菜单头写被右键的那个名字、引擎写「只改这一条会话」。危险项放最后、前面一条线、字用 err。菜单里**不放图标**，只有字：图标在菜单里只增加扫读成本。不做二级菜单。

同一时间只开一个浮层，开新的自动关旧的。

### 5. 键盘

| 键 | 菜单 | 选择器 | 信息卡 |
| --- | --- | --- | --- |
| Esc | 关，焦点回触发钮 | 同 | 同 |
| ↑ ↓（循环）· Home End | ✓ | ✓（有搜索框时焦点留在框里，↑↓ 移动高亮行） | —— |
| ⏎ | 选中并关 | 选中并关 | —— |
| Tab | 关，焦点往下走 | 同 | 在卡内控件间走 |

鼠标悬停和键盘高亮是**同一个**「当前行」，不会出现两行同时亮。不做字母跳转（中文菜单用不上）。窗口大小变了就关。

S11 里的浮层已经按这套写成一份（`pop` / `popPos`），菜单的 ↑↓⏎ 可以试。

## 五、9.5 展开收起：三档

| 档 | 时长 | 用在 |
| --- | --- | --- |
| 快 | 120 ms | 浮层、树的箭头旋转、JSON 节点箭头、悬停底色、淡入淡出 |
| 中 | 180 ms | 编辑栏、frontmatter、树 / JSON 的子节点展开 |
| 慢 | 240 ms | 整列（目录、属性区、聊天）、整行（调试栏） |

曲线一律 `cubic-bezier(.2, 0, 0, 1)`，进出同一条。

**收起时内容怎么处理**：外层收宽 / 收高，**里层保持原来的尺寸**，被外层裁掉。所以文字不会一帧一帧地重排换行。里层同时淡出（快档）；展开时外层先长、里层晚 60 ms 淡入。滑出的方向按「它贴着哪条边」：目录向左、聊天和属性区向右、调试栏向下、编辑栏向上。

**规矩**：

1. **动画中再点一次 = 从当前位置反向**，不忽略、不排队。忽略第二次点击正是用户第 11 条抱怨的「点了没反应」
2. 拖动手柄时不做动画，双击回默认值时走慢档
3. 一次展开超过 50 个子节点的，不做高度动画，直接出
4. 系统开了「减少动态效果」：只保留 80 ms 的淡入淡出
5. 收起后里层加 `inert`，Tab 键不会走进看不见的东西里

## 六、9.6 Tab

### 1. 覆盖式打开

三态：**预览 → 打开 → 固定**。

| | 怎么来 | 长什么样 |
| --- | --- | --- |
| 预览 | 目录里**单击**文件 | 名字 `--tool-text-2`、不加粗（当前页签也不加粗），图标灰。同一时间最多一个 |
| 打开 | 双击页签 · 双击目录里的文件 · 开始改内容 · 展开编辑栏 · 右键「保持打开」 | 普通页签 |
| 固定 | 右键「固定」 | 排最左、最宽 150，关闭钮的位置换成图钉（点图钉 = 取消固定） |

- 单击下一个文件时，**只盖预览页签**；没有预览页签就新开一个预览页签。未保存和固定的永远不会被盖
- **不用斜体**：中文字体没有斜体，浏览器会硬斜切，很难看。浅一档的颜色加不加粗，已经足够和普通页签区分
- 悬停提示写「预览页签：下一次单击别的文件会盖掉它，双击留下」

数据键：`tabs[].preview` · `tabs[].pinned`。

### 2. 右键菜单（演示态 10）

```
README.md
关闭                    ⌘W
关闭其他              3 个
关闭右侧              2 个
关闭已保存的          3 个
─────────
固定 / 取消固定
保持打开              双击     ← 只在预览页签上出现
─────────
在目录中显示
带进会话
─────────
复制路径
在访达中显示
```

- 三个「关闭…」后面写**真会关掉的个数**，未保存和固定的不算在内。一个都关不掉时整项置灰。点之前就知道结果
- **在目录中显示**：目录关着就打开（窄窗是浮层），展开到它所在的目录，滚到它，那一行描一圈 accent 边，1.2 s 后退回普通的当前行（演示态 13）
- 我补的：关闭右侧 · 关闭已保存的 · 保持打开 · 带进会话。没加「复制相对路径」「在新窗口打开」：一个是「复制路径」的变体，一个现在没有这个能力

文件 `⋯` 里也加了「在目录中显示」，`.dc.html` 的 `⋯` 加了「存为模板…」（见 §十）。

## 七、9.7 图标

**56 颗**，路径在 `ui/icons.js`，图表在 `S16`。

规矩（统一比单颗好看重要，所以先定规矩）：

- 16 × 16 网格，活动区 2.5–13.5
- 线宽一律 1.4，圆端点、圆转角，**只描边、不填色**
- 容器（框、页、夹）圆角 1.5
- 点状元素：「更多」用 r 0.75 的小圆，感叹号和 i 的点用零长线段

页签和树里的「未保存」「体检」状态点仍用 6 px 实心圆点（CSS），不走图标：它们要在 6 px 里读得出颜色，线稿做不到。

## 八、9.8 进度条

**不再有独立的进度条。** 一个模块在忙，就让**它自己状态栏下沿那条 1 px 分隔线**变成 2 px、一段 accent 在里面流动，做完退回 1 px。模块自己的事只在自己的线上走。

| 哪里 | 什么时候 | 演示态 |
| --- | --- | --- |
| 目录头下沿 | 重建索引。悬停这条线写进度「37 / 120」 | 15 |
| Tab 条下沿 | 当前文件在渲染 / 体检 | 文件 ⋯ →「重新体检」 |

## 十、§三 欠的两件

### 1. 评论指针：工具栏不要这一颗，S2 不加 `comment` 命令

评论不是另一种指针，是**选中之后的一个动作**：先点选一个元素，再在属性区的「评论」页写。这样只用 S2 已经有的 `pick`，不用改 S2。你们「画了点不动比少画一颗糟」的判断是对的；而且两颗互斥的指针，多数人不会去切。

编辑栏里 `.dc.html` 的指针组只剩「点选」一颗。

### 2. 起始模板：整组不出

项目里没有模板时，「起始模板」整组不出（演示态 34）。「复制一份现有稿…」不能跟着消失，所以挪到底部左边，成一个文字链接「从现有稿复制…」。

「用户永远不知道有模板」这件事，解法放在**模板从哪来**的地方：`.dc.html` 的 `⋯` 里加了「存为模板…」。用户存过一次，这一组就出现了。有模板时组里第一项是「空白」。
