**优先级**：高。M1 最后一块拼图，做完 M1 就闭环了。

### 3. S6 版本对比（M4-1）

**排期**：M4（画布与对比）
**用途**：两版并排对比，滚动同步，变更处高亮。
**和 S4 的关系**：同一份变更数据的另一种投影 —— S4 是清单，S6 是画面。

**已有定义**（`doc/08`）：

```
两版并排。左右各一个 iframe，滚动同步，变更处高亮。
和 S4 是同一份数据的另一种投影。
```

**数据契约**（来自 S4 变更清单）：

```json
{
  "file": "日志.dc.html", "from": "v216", "to": "v217",
  "changes": [
    { "level": "L1", "kind": "prop_added", "target": "onRetry", "at": "L45" },
    { "level": "L2", "kind": "style_changed", "target": "日志行", "prop": "line-height", "from": "20px", "to": "22px" }
  ]
}
```

**需要设计的**：
- 并排布局（左右各一个 iframe 预览）
- 滚动同步的交互
- 变更处高亮的样式（按四级着色：L1 契约 / L2 取值 / L3 文案 / L4 等价）
- 版本选择器（选哪两版对比）
- 状态：单版查看、两版对比、无差异、差异很多

### 4. S10 组件 props 面板（M4-2）

**排期**：M4
**用途**：打开一份组件稿时，把 `data-props` 里 `editor` 非 `null` 的项渲染成控件，
改了就走运行时的 `__dcSetProps` 重渲染。

**⚠️ 注意**：这不是 S7 节点属性面板。S7 是选中一个节点改它的样式/属性/文案；
S10 是打开组件稿时调它的 props（文本、枚举、布尔、数字）。

**props 契约**（`editor` 取值）：

| editor | 控件 | 例子 |
| --- | --- | --- |
| `"text"` | 文本框 | 按钮文案 |
| `"enum"` | 下拉/单选 | `tone: "primary" \| "danger" \| "ghost"` |
| `"boolean"` | 开关 | `disabled: true/false` |
| `"number"` | 数字控件 | `count: 5` |
| `null` | 不给控件，只显示值 | `onClick: () => void` |

**数据示例**：

```json
{
  "props": [
    { "name": "text", "editor": "text", "default": "点击我", "tsType": "string" },
    { "name": "tone", "editor": "enum", "options": ["primary", "danger", "ghost"], "default": "primary" },
    { "name": "disabled", "editor": "boolean", "default": false }
  ]
}
```

**规矩**：演示态切换钮不要放进 props 面板（一个状态两个入口，点下去不知道哪个会生效）。

## 三、内容决定（不需要画，只需要你定内容）

### 任务.dc.html 的错误卡内容

`PC 端/任务.dc.html` 的错误卡有两个洞没有内容：

```html
<dc-import name="PC 错误卡" meta="{{ decideMeta }}" actions="{{ decideActions }}">
```

**需要你定的是内容**（不是形制）：
- `meta`：那张错误卡该显示哪几行信息？类型是 `{label: string; value: string}[]`
- `actions`：该有几颗什么按钮？类型是 `{label: string; kind?: 'primary'|'danger'|'ghost'; act?: ()=>void}[]`

这是设计决定，我们不替你定。定了之后告诉我们，我们去填。
